=== Hostelworld Hub Builder ===
Requires the Hostelworld Blog Hubs plugin (5.8.1 or later recommended).

Hub builder (its own item in the admin menu). Upload one spreadsheet (template included) with one row
per hub page. You get a preview with checks for every row, then the pages are
created as drafts with their template, parent page, address, hub settings,
Yoast SEO title and meta description, and hero photo (downloaded into the
Media Library with the credit as caption and the alt text).

Existing pages are never changed. Each batch can be undone from the same
screen: its pages still in draft go to the bin.

Deactivating or deleting this plugin leaves every page it created as it is.
